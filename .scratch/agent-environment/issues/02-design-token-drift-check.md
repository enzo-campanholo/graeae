# 02: A check that the design tokens agree

Status: needs-triage
Blocked by: none

**What was seen:** the tokens in `DESIGN.md`'s frontmatter, `.impeccable/design.json` and `src/app/app.css` drift apart on nearly every UI ticket, and reviewers catch the mismatches by hand. The three use different shapes: YAML frontmatter with `-light` names, the sidecar's `colorMeta` ramps (generated by the impeccable plugin's documenter), and CSS custom properties per theme.

**What to decide:** which of the three is authoritative, and how the light and dark names map between them.

**What to build:** a check that fails on a mismatch, either in the pre-commit hook or through the impeccable plugin's own `design-sidecar-stale` detector.
